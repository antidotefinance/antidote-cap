# Security policy

Report vulnerabilities in levcap privately through GitHub security advisories:
https://github.com/antidotefinance/antidote-cap/security/advisories/new

Please do not open public issues, pull requests or discussions for vulnerabilities. Include the
instruction and steps or a transaction that reproduces the problem. We will acknowledge the report
in the advisory and coordinate a fix and disclosure there.

The security.txt embedded in levcap (programs/levcap/src/lib.rs) points here. The other Antidote
programs have their policy at https://github.com/antidotefinance/antidote-programs.
